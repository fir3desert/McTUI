# McTUI++

> Minecraft Server Management TUI for Linux

**McTUI** is a terminal-based interface for managing Minecraft servers from a single application.

The goal is to provide an easy and modern way to manage Minecraft servers without relying on multiple scripts and terminal windows.

## ✨ Features

* 🖥️ **TUI interface** inspired by btop
* 🎮 **Minecraft server management**

  * Vanilla
  * Fabric
  * Forge
  * NeoForge
* 📦 **Server installer** with Minecraft version selection
* ☕ **Java management** with automatic Java version handling
* ▶️ **Start / Stop / Restart** servers
* 📊 **CPU & RAM monitoring**
* 👥 **Online player monitoring**
* 📜 **Live server console & logs**
* 🧩 **Mod manager**
* 🌱 **Modrinth integration** for searching and installing mods
* 📁 **File manager & built-in editor**
* 🌐 **Playit.gg integration** for public server access
* 💬 **Discord webhook integration**
* 🔔 **Discord notifications** for server and player events
* 🎨 **Multiple themes**
* 🌍 **English / Spanish**
* 🖱️ **Mouse support**
* ⌨️ **Keyboard shortcuts**
* 💾 **Persistent server configuration**
* 🔄 **Automatic detection of running servers**
